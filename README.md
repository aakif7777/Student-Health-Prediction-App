# Student Health Risk Prediction System

A Machine Learning based Flask web application that predicts student health conditions.

## Prediction Classes

- Fit
- At-Risk
- Unhealthy

## Machine Learning Model

Final Model:
XGBoost Classifier

Performance:
Balanced Accuracy: 0.94947

## Technologies Used

- Python
- Flask
- XGBoost
- Pandas
- NumPy
- Scikit-learn
- Joblib

## Features

- Sleep Duration
- Heart Rate
- BMI
- Calorie Expenditure
- Step Count
- Exercise Duration
- Water Intake
- Diet Type
- Stress Level
- Sleep Quality
- Physical Activity Level
- Smoking and Alcohol
- Gender
